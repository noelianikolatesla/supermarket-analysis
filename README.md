# 🛒 Data Analysis - Supermarket Sales (Python)

### 📌 Descripción
Este proyecto realiza un análisis exploratorio de datos (EDA) sobre ventas de un supermercado.  
El objetivo es detectar qué categorías generan más beneficio y cuáles podrían estar causando pérdidas para apoyar decisiones de negocio.

### 📊 Tecnologías usadas
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

### 📈 Resultados principales
✔ La categoría más rentable fue **Technology**  
✖ La categoría menos rentable fue **Furniture**  
➡ Se proponen acciones de mejora como revisar precios, promociones y stock.
